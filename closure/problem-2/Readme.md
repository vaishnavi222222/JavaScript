The initial function causes the output to be Hello undefined! for every name in the array. This happens because var has function-level scope. All three setTimeout calls share the same i variable. By the time the setTimeout callbacks are executed, the loop has already completed, and i equals 3, which is out of range for the array — hence the undefined.
To fix this, we can use an IIFE (Immediately Invoked Function Expression). With this approach, a new scope is created for each iteration, and the current value of i is stored in a new variable (commonly called index). This captured value remains available for each setTimeout callback, so the correct name from the array is printed.
Another way to solve the issue is by using let instead of var. The let keyword introduces block-level scope, meaning that each loop iteration has its own separate i value. When the setTimeout runs, it references the correct i value that was current at the time of the loop iteration. As a result, each name is correctly printed with a delay.
